# P1 Draft Contracts

These mission-local artifacts express the P1 planning boundary. They are Draft
and are not implementation authorization.

- `resolved-invoice-configuration-v1.schema.json` defines the current resolved
  master-data payload consumed by P2, P5, and P6.
- `p1-contract-manifest.json` records ownership, lifecycle, and P0 dependency.

Implementation will publish additive API/event fragments and frozen valid and
invalid fixtures under P1-owned repository paths.
